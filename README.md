# IELTS Writing Task 1: длина ответов по типам заданий

## Источники вдохновения и консультации

Визуальный стиль графика был вдохновлён материалами курса, примерами графиков с портала X.com, а также работой Nico Künel Peltze (@nico_kinel):

https://twitter.com/nico_kinel/status/1838497997602042097

В процессе подготовки кода, оформления графика и интерпретации статистического теста я также консультировалась с ChatGPT

Код и визуализация были адаптированы под данные моего проекта: корпус текстов IELTS Writing Task 1

## Описание проекта

Данный финальный график основан на моём более раннем проекте, посвящённом созданию и анализу корпуса текстов IELTS Writing Task 1

В исходном проекте был подготовлен корпус модельных ответов IELTS Writing Task 1. Для каждого текста были определены тип задания и длина ответа в словах. В финальной визуализации эти данные используются для анализа того, как длина ответов различается в зависимости от типа задания

## Почему есть две версии графика

В проекте представлены две версии финальной визуализации:

- английская версия
- русская версия

Изначально график был подготовлен на английском языке, потому что корпус связан с экзаменом IELTS и письменным заданием на английском языке. Английская версия выглядит естественно для темы IELTS и может быть уместна в контексте материалов по обучению академическому письму

Русская версия была подготовлена дополнительно для презентации и обсуждения результатов на русском языке. В ней переведены заголовки, подписи осей, легенда, примечания и текстовый вывод

## Исследовательский вопрос

Различается ли длина ответов IELTS Writing Task 1 в зависимости от типа задания?

## Данные

Для построения графика используется файл `lengths.json`

Он содержит:

- тип задания
- русское название типа задания
- длину текста в словах

В корпусе представлены разные типы заданий IELTS Writing Task 1, например:

- линейный график
- столбчатая диаграмма
- круговая диаграмма
- таблица
- карта
- описание процесса
- смешанный тип

## Минимум IELTS Writing Task 1

В IELTS Writing Task 1 обычно требуется написать не менее 150 слов. Поэтому на графике отмечен порог в 150 слов

Этот порог используется как ориентир: он помогает увидеть, насколько типичная длина ответа для разных типов заданий находится выше минимального требования

## Финальные графики

### Английская версия

Файлы:

- `good_graph_Krylova_en_09_05_2026.R`
- `good_graph_Krylova_en_09_05_2026.png`

### Русская версия

Файлы:

- `good_graph_Krylova_ru_09_05_2026.R`
- `good_graph_Krylova_ru_09_05_2026.png`

Обе версии графика состоят из двух частей:

1. Верхний график показывает типичную длину ответа для каждого типа задания относительно порога в 150 слов
2. Нижний график показывает разброс длины ответов внутри каждого типа задания

## Статистический тест

Для проверки различий между типами заданий был использован тест Краскела–Уоллиса

Результат:

`p = 0.005131`

Так как p-value меньше стандартного порога 0.05, можно сделать вывод, что различия в длине ответов между типами заданий статистически значимы

## Основной вывод

В корпусе наблюдаются различия в длине ответов между типами заданий IELTS Writing Task 1

Наиболее развёрнутые ответы характерны для смешанного типа задания, а самые короткие — для описания процесса
